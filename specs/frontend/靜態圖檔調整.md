# 靜態圖檔調整紀錄

本文件記錄將網站圖片由 Nuxt Image／CDN 改為原生 `<img>` 與 `assets/img` 靜態資源的調整，方便日後還原。

## 調整內容

### 頁面與元件

- `pages/about.vue`
  - `Certification.webp`：`<nuxt-img src="cloudfront/Certification.webp">` 改為 `<img src="~/assets/img/Certification.webp">`。
- `pages/faq.vue`
  - `qa.webp`、`qa-2.webp`：由 `<nuxt-img>` 與 CloudFront alias 改為原生 `<img>` 與 `~/assets/img/...`。
- `components/FooterComponent.vue`
  - `QRcode.webp`：由 `<nuxt-img>` 與 CloudFront alias 改為原生 `<img>` 與 `~/assets/img/QRcode.webp`。
- `pages/labor-info.vue`
  - 圖片顯示元件由 `<nuxt-img>` 改為原生 `<img>`。
  - 移除 Nuxt Image 專用屬性：`sizes`、`format`、`quality`、`fit`、`densities`。
  - `01.webp` 至 `19.webp` 改由 `~/assets/img` 靜態匯入，`laborTabs` 使用匯入後的圖片 URL，不再使用 CloudFront URL。
- `components/LoadingComponet.vue`
  - 原本已使用 `<img src="~/assets/img/tail-spin.svg">`，未修改。

### Nuxt 與套件設定

- `nuxt.config.ts`
  - 移除 `image` 設定（圖片目錄、CloudFront domain 與 alias）。
  - 從 `modules` 移除 `@nuxt/image`。
- `package.json`
  - 移除 `@nuxt/image` 依賴。
- `package-lock.json`
  - 同步移除 `@nuxt/image` 及不再需要的相關依賴紀錄。
- `composables/useLaborSiteConfig.ts`
  - 更新註解，說明頁面圖片使用 `assets/img`；SEO meta 圖片仍須使用外部可存取的絕對網址。

## 未改成站內靜態路徑的圖片

SEO 的 `og:image`、Twitter Card 與結構化資料不是畫面中的 `<img>`，瀏覽器或社群爬蟲需要可公開存取的絕對網址，因此下列設定仍保留 CloudFront URL：

- `pages/about.vue` 的 `usePageSeo().image`
- `pages/faq.vue` 的 `usePageSeo().image`
- `pages/labor-info.vue` 的 `usePageSeo().image`
- `composables/useLaborSiteConfig.ts` 的 `defaultOgImage`

## 如何還原為 Nuxt Image／CloudFront

1. 在 `package.json` 加回 `"@nuxt/image": "^1.7.0"`，然後執行 `npm install`。
2. 在 `nuxt.config.ts` 的 `modules` 加回 `@nuxt/image`。
3. 在 `nuxt.config.ts` 加回以下設定：

```ts
image: {
  dir: "assets/img",
  domains: ["https://d1vjl2px6hqzku.cloudfront.net"],
  alias: {
    cloudfront: "https://d1vjl2px6hqzku.cloudfront.net",
  },
},
```

4. 將上述頁面與元件的 `<img>` 改回 `<nuxt-img>`，圖片來源可改回 `cloudfront/檔名.webp`。
5. 若需要圖片最佳化，再加回原本使用的 `format`、`quality`、`densities`、`sizes` 與 `fit` 屬性。
6. `pages/labor-info.vue` 若改回 CloudFront alias，可移除檔案頂部的 `image01` 至 `image19` 靜態 import，並將每個 `src: imageXX` 改回 `src: "cloudfront/XX.webp"`。

## 驗證方式

```bash
npm install
npm run build
```

建置後可搜尋 `nuxt-img` 與 `cloudfront/`，確認是否已完全還原或完全移除。
